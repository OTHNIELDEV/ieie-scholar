## 2. 화면별 명세

### 2.1 홈 [P0]
- 검색창(일반/AI 토글, 자동완성: 논문·저자·키워드·간행물)
- 이번 주 BEST, 신규 등재, **다가오는 학술대회(D-day + 프로그램 링크)**, 소사이어티별 최신 논문 탭
- 학회 독점 콘텐츠 영역: 웹진, 서울IT포럼, 해동 일본기술정보 ★
- 로그인 시: 팔로우 기반 피드, 미열람 알림

### 2.2 통합검색 [P0]
| 요소 | 명세 |
|------|------|
| 모드 | 키워드(BM25+벡터 하이브리드) / AI 답변(근거 인용) |
| 범위 | 전체 · 제목 · 초록 · 저자 · 키워드 · **본문(원문 청크)** ★ · **그림/표 캡션** ★ |
| Facet | 자료유형, 연도(범위 슬라이더), 소사이어티, 간행물, 세션/트랙 ★, 언어, OA 여부, 수상 ★, 원문 유형(born-digital/OCR), 코드 공개 ★ |
| 정렬 | 관련도 · 최신 · 피인용 · 이용수 |
| 결과 카드 | 제목(한/영), 저자(링크), 소속, 간행물·연도, 한 줄 AI 요약, 키워드 칩, 배지(OA/수상/코드), 액션(서재·인용·PDF) |
| 보조 | 동의어·오타 교정, "검색 결과 저장→알림", URL 공유 가능 상태 |
| 상세검색 | 조건 5개 이상, 불리언, 필드 지정, ISSN, DOI |
| 성능 | p95 < 300ms (Typesense) |

### 2.3 논문 상세 [P0]
1. 헤더: 제목(한/영), 저자(+ORCID 아이콘, 소속, 교신저자 표시), 간행물·권호·페이지, DOI, 발표 세션/일시 ★, 수상 배지 ★
2. 액션 바: PDF 보기(인앱 뷰어) · 다운로드 · 인용(APA/IEEE/BibTeX/RIS/한글 각주) · 서재 담기 · 공유 · 오류신고 · **AI 워크스페이스 열기** ★
3. 탭: 초록/키워드 · AI 요약(한줄/목차/연구방법/쉬운/영문) · **그림·표·수식** ★ · 참고문헌(DOI 링크, 내부 논문 연결) · 피인용(내부+Crossref+OpenAlex, 인용 문맥 표시 ★) · 이용 통계 · 토론 ★
4. 사이드: 유사 논문(벡터), 같은 세션 논문 ★, 같은 연구실 논문 ★, 코드/데이터셋 링크 ★, 메트릭(조회·다운로드·인용)
5. SEO: `citation_*` 메타, JSON-LD, OG 이미지(제목+저자 자동 생성)
6. 접근 제어: OA → 즉시, 회원/기관 → 인증 후, 비회원 → 미리보기 2쪽 + 구매/회원가입 유도

### 2.4 권호·학술대회 상세 [P0] ★
- 학술대회: **트랙 → 세션 → 논문** 트리, 시간표 뷰(일자별), 장소 맵, 세션 체어, 발표 유형 아이콘
- 저널: 권호 목록, 특집호 표시, 편집위원
- 일괄 작업: 전체/세션 선택 → 서재 담기 · RIS 내보내기 · ZIP 다운로드(권한 시)
- 통계: 논문수, 소사이어티 분포 차트, 참여 기관 Top 10

### 2.5 프로그램북 [P1] ★
- 모바일 우선 시간표, 내 일정 담기, 세션 알림(푸시), 발표자료·포스터 열람, 현장 QR → 논문 상세
- 학술대회 전 공개 → 대회 트래픽 흡수

### 2.6 저자 프로필 [P0 기본 / P1 클레임] ★
- 논문 목록(연도·간행물 필터), 지표(논문수·인용·h-index·소사이어티 활동), 공저자 그래프(D3), 소속 이력
- 클레임: ORCID 로그인 또는 이메일 인증 → 본인 표기 병합/분리 요청, 프로필 편집, Preprint/슬라이드 업로드, OA 전환 신청
- 동명이인 분리 UI(관리자 승인)

### 2.7 연구실 페이지 [P1] ★
- PI + 멤버 논문 자동 집계, 연구 키워드 클라우드, 연도별 산출 차트, 홈페이지·채용 링크, 기업 열람 통계(B2B)

### 2.8 소사이어티 허브 [P1] ★
- 6개 소사이어티별 최신 논문·행사·수상·세부 기술분류, 운영진, 뉴스레터 구독

### 2.9 트렌드 대시보드 [P1] ★
- 키워드 연도별 빈도(상승/하강), 소사이어티별 비중 변화, 기관별 산출, 신규 등장 키워드 탐지, 주간 AI 브리핑(기업 플랜)

### 2.10 AI 리서치 [P0 검색·요약 / P1 딥리서치·비교 / P2 리뷰어] ★
| 모드 | 입력 | 출력 | 가드 |
|------|------|------|------|
| AI 검색 | 자연어 질문 | 근거 인용 답변(각 문장에 [n] 인용, 클릭 시 원문 페이지·bbox 하이라이트) + 참고 논문 표 | 근거 없는 주장 금지, 인용 ID 검증, 1,000자 입력 제한 |
| 논문 QA | 논문 1편 + 질문 | 해당 논문 청크 기반 답변 | 범위 외 질문 거부 |
| 요약 | 논문 | 한줄/목차/방법/쉬운/영문, 핵심 수식·그림 포함 | 배치 사전 생성 |
| 번역 | 논문·문단 | 한↔영, 원문-번역 분할 뷰, 학회 용어집 반영 | 캐시 |
| 비교표 | 논문 2~10편 | 성능 지표 교차표(단위 정규화), 차이점 서술 | 추출 신뢰도 표시 |
| 딥리서치 | 주제 | 계획→검색 로그→A4 5~10쪽 보고서(Markdown/DOCX), 참고문헌 자동 | 검증 패스 |
| 리뷰어 모드 | PDF 업로드 | 유사 논문 top 20, 신규성·중복 가능성 코멘트, 참고문헌 누락 제안 | 투고 시스템 연계 |
| 외부 PDF 분석 | 업로드 | DBpia AI Reader 동급(요약·번역·QA) | 사용자 사적 공간 |
- 쿼터: 비회원 월 10회, 회원 월 100회, Pro/기관 무제한(공정이용 한도)
- 대화 이력 저장, 인용 논문 → 서재 저장, 보고서 내보내기

### 2.11 내 서재 [P0] ★(공유·노트)
- 폴더, 태그, 노트(마크다운), **공유 링크/연구실 공유 폴더**, RIS/BibTeX 내보내기, Zotero 동기화(P2)

### 2.12 팔로우·알림 [P1]
- 저자·키워드·간행물·연구실·세션 팔로우 → 신규 등재/인용 발생/학술대회 일정 알림(이메일·웹푸시)
- 검색식 저장 알림

### 2.13 인용 관리 [P1] ★
- 웹 기반(모든 OS), 스타일: APA·IEEE·Chicago·학회 한글 양식·국문 각주, BibTeX/RIS/EndNote XML, 한글(HWP) 참고문헌 붙여넣기 포맷, Chrome 확장(P2)

### 2.14 Open API [P0 서지 / P1 원문·AI] ★
```
GET /api/v1/search?q=&type=&year=&society=&page=      (무료, 60rpm)
GET /api/v1/papers/{id|doi}                             서지+초록+키워드+인용수
GET /api/v1/papers/{id}/references | /citations
GET /api/v1/authors/{id} | /authors/search
GET /api/v1/venues/{slug}/issues
GET /api/v1/papers/{id}/fulltext   (권한·종량)
POST /api/v1/ai/search              (종량, 토큰 과금)
GET /api/v1/export/bulk?since=      (메타+임베딩 덤프, 라이선스 티어)
```
- OpenAPI 3.1 문서, API 키, 레이트 리밋, 사용량 대시보드, OAI-PMH 엔드포인트(도서관 하베스팅)

### 2.15 관리자 [P0]
- 인제스트: PDF 업로드/일괄, 파싱 결과 교정(제목·저자·초록·참고문헌), 품질 플래그 큐
- 학술대회 관리: 세션/트랙 CSV 업로드, 논문-세션 매핑, 수상 지정
- 저자 명확화 검수(병합/분리 제안 승인)
- DOI 등록(Crossref XML 생성·전송), OpenAlex/KCI 동기화 상태
- 회원 연동(학회 회원 DB CSV/API), 기관·IP 관리, API 키·플랜
- 통계: 이용·검색어·AI 비용·전환율
