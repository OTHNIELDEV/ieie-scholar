# 08. 비즈니스 모델 · 요금제 제안

> 원칙: **회원 가치 극대화(무료) + 기업·기관·API에서 수익** — DBpia의 "단건 9,000원" 모델과 정반대 포지션

---

## 1. 수익 구조 비교

| 수익원 | DBpia | IEIE Scholar |
|--------|-------|--------------|
| 기관 구독 | 주력(대학 90%) | 유지(도서관 패키지, AI 포함) — 가격은 DBpia 대비 낮게, 전자공학 단과대·학과 단위 상품 |
| 개인 단건 | 9,000원/편 | 비회원 3,000원/편 또는 **회원가입 유도**(학회 회비에 포함) |
| 개인 구독 | 월/분기, AI 플랜 유료화 | 회원 무료 / 비회원 Pro(AI 포함) |
| 데이터 판매 | 누리미디어 수익 | **학회 직접 라이선스**(AI 학습, 벌크 메타) |
| B2B 기술동향 | 없음 | ★ 특별회원 기업 대상 대시보드·브리핑 |
| 학술대회 연계 | 없음 | ★ 등록비 번들, 프로그램북 광고, 가상 전시 부스 |
| API | 신청제, 서지 한정 | 서지 무료 + 원문/AI 종량 |
| 채용·인재 | 없음 | ★ 연구실 페이지 기반 리크루팅 라이선스 |

## 2. 요금제 (안)

### 개인
| 플랜 | 가격 | 포함 |
|------|------|------|
| Free | 0 | 서지·초록·OA 원문, 미리보기 2쪽, AI 월 10회, 서재 100편 |
| **Member**(학회 회원) | 회비 포함 (0 추가) | 전 원문, AI 월 100회, 서재 무제한, 저자 클레임, 프로그램북 |
| Pro | 월 9,900원 / 연 99,000원 | Member + AI 무제한(공정이용), 딥리서치 월 30회, 비교표, 리뷰어 모드, 외부 PDF 분석 |
| 단건 | 3,000원/편 | 비회원 원문 1편 (DBpia 9,000원 대비 1/3) |

### 기관
| 플랜 | 가격(연) | 포함 |
|------|----------|------|
| Library Basic | 150만~600만원 (FTE 규모별) | 원문 무제한, IP/SSO, 이용통계, OAI-PMH |
| Library AI | Basic + 50% | AI 무제한, 딥리서치, 학과 대시보드 |
| Enterprise(기업) | 500만~3,000만원 | AI + ★기술 레이더(키워드·경쟁사·연구실 추적), 주간 AI 브리핑, 인재 탐색, API Business 티어, 특별회원 등급 연동 할인 |

### API / 데이터
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | 0 | 서지 60rpm, 월 10만 콜 |
| Dev | 월 5만원 | 300rpm, 원문 메타+초록, AI 검색 월 1천 콜 |
| Business | 월 50만원~ | 1,000rpm, 원문 접근, AI 종량(토큰 단가+30%), 벌크 덤프 |
| 데이터 라이선스 | 건별 협상(수천만원~) | AI 학습용 원문+메타, 연 1회 갱신 |

## 4. 핵심 리스크와 대응
| 리스크 | 대응 |
|--------|------|
| DBpia 독점 전송권 계약 | 계약서 검토 → 비독점 전환 협상 또는 만료 시점에 맞춘 런칭. 병행 유통 시에도 **학회 사이트가 1차 공개처**가 되도록 당일 등재로 선점 |
| 기관 도서관의 DBpia 패키지 관성 | 전자공학 단과대 단위 저가 상품 + KERIS 대학라이선스 등록 추진 |
| AI 저작권(저자 동의) | 투고 규정에 AI 활용·OA 조항 신설, 과거 논문은 옵트아웃 안내 |
| AI 비용 폭증 | 캐시·배치·Haiku 라우팅, 플랜별 쿼터, 비용 대시보드 |
| 저자 명확화 오류(명예) | 검수 큐 + 클레임 기반 정정, 변경 이력 공개 |
