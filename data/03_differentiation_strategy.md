## 2. 차별화 10대 전략

### ① 학술대회 중심 구조화 (DBpia 최대 약점 공략)
- 논문집을 **대회 → 트랙/소사이어티 → 세션 → 발표(구두/포스터)** 트리로 제공
- 세션 체어, 발표 시간, 발표 슬라이드/포스터 PDF, 우수논문상 배지
- 대회 개최 전 "프로그램북 = 플랫폼" 으로 전환 → 참가자가 현장에서 플랫폼을 쓰게 만들어 **트래픽을 학회 행사와 결합**
- 효과: 연 1,800편이 **발표 당일** 서비스 (DBpia는 수주~수개월 지연)

### ② 저자 아이덴티티 & 연구실 페이지
- 저자 명확화 엔진(ORCID · KRI · 소속 · 공저자 그래프 · 이메일 도메인)
- 저자 프로필: h-index(자체+OpenAlex), 연도별 발표, 소사이어티 활동, 수상, 공저자 네트워크 그래프
- **연구실(Lab) 페이지**: 교수 + 소속 학생 논문 자동 묶음, 대학원 진학 희망자·채용 기업의 핵심 탐색 경로
- 저자 클레임(본인 인증) → 본인 논문 Open Access 전환·Preprint 업로드 권한

### ③ 인용 네트워크 개방 연동
- Crossref · OpenAlex · Semantic Scholar · KCI 인용 데이터 통합 → DBpia의 "자체 범위 피인용" 한계 극복
- 인용 문맥(citation context) 추출: "이 논문이 어떤 문장에서 인용됐는가"
- 역방향: IEIE 논문이 IEEE/SCIE 논문에 인용된 경우 추적 → 학회 성과 홍보 자료 자동 생성

### ④ 전자공학 특화 멀티모달 AI
| 기능 | 설명 | DBpia |
|------|------|-------|
| 그림/표 검색 | "28nm CMOS LNA 측정 결과 표", "FinFET 단면도" → 추출된 Figure/Table 단위 검색 | ✗ |
| 수식 검색 | LaTeX/MathML 인덱싱, 수식 유사 검색 | ✗ |
| 스펙 테이블 비교 | 여러 논문의 성능표(전력, 면적, 주파수, SNR 등)를 자동 정규화해 비교표 생성 | ✗ |
| 코드/데이터셋 링크 | GitHub, IEEE DataPort, 공개 데이터셋 자동 연결 | ✗ |
| 영↔한 기술 번역 | 전자공학 용어집(학회 표준용어) 기반 번역 | 범용 번역 |
| 리뷰어 모드 | 투고 논문 vs 기존 논문 유사도·신규성 사전 점검(투고 시스템 연계) | ✗ |
| 딥리서치 | 원문 청크 기반, 수식·표 인용 포함 보고서, 출처 페이지 좌표 표시 | 초록 수준 |

### ⑤ Open Access + 회원 무료 + 저렴한 API
- 학회 회원: 전 논문 무료(회비에 포함) → **"내 논문 9,000원 주고 보기" 구조 해체**
- 비회원: 학술대회 논문 무료 공개(Diamond OA), 논문지 엠바고 12개월 후 공개 검토
- Open API: 서지 **무제한 무료**, 원문·AI는 저렴한 종량제(토큰/건당) → 스타트업·연구실 유입
- 효과: Google Scholar·OpenAlex 색인 확대 → 인용 증가 → 학회 저널 영향력 상승이라는 선순환

### ⑥ 기업 B2B 기술동향 상품
- 특별회원(삼성·SK하이닉스·LG 등 골드/실버/브론즈) 대상 **기술 레이더 대시보드**: 키워드 트렌드, 신규 연구실, 경쟁사 발표 추적, 주간 AI 브리핑(해동 일본기술정보 포함)
- 채용 연계: 연구실 페이지 → 기업 리크루팅(인재 탐색 라이선스)

### ⑦ 커뮤니티 & 네트워크
- 논문 단위 Q&A(저자 답변 배지), 세션 토론 스레드, 학술대회 미팅 매칭
- 발표 영상/슬라이드 업로드, 포스터 세션 가상 전시
- DBpia 댓글은 사실상 0건 → "저자가 상주하는" 커뮤니티로 차별

### ⑧ 글쓰기·투고 워크플로우 일체화
- 웹 기반 인용 관리(macOS·모바일 지원 — Citeasy 약점), 학회 템플릿(한글·LaTeX·Word) 자동 서식
- 투고 시스템(JAMS 등)과 연동: 플랫폼에서 참고문헌 수집 → 투고 → 심사 → 게재 → 자동 등재
- Zotero/Mendeley/Obsidian 커넥터, BibTeX/RIS 내보내기

### ⑨ 데이터 주권 & 리서치 인프라
- 학회가 **직접** AI 학습 데이터 라이선스 판매(DBpia가 가져가던 수익 회수)
- 연구자용 벌크 다운로드(메타+임베딩) 데이터셋 공개 → 학계 레퍼런스 데이터셋화
- DOI 100% 등록(Crossref), ORCID 연동, OpenAlex 공급 → 국제 가시성

### ⑩ 성능·UX
- SSR/ISR로 즉시 렌더(DBpia의 빈 placeholder 문제 회피), Core Web Vitals 90+
- 검색 응답 < 200ms (Typesense/Meilisearch + pgvector 하이브리드)
- 모바일 우선, 다크모드, 키보드 내비게이션, PWA 오프라인 읽기
- 접근성(WCAG 2.1 AA), 영문 UI 완전 지원(국제대회·해외 연구자)

## 3. "하지 말아야 할 것"
1. 1,119개 학회 전체를 모으려는 시도(범용화) — 전자공학 깊이에 집중
